# Player Hitbox (Fabric, Minecraft 1.21.11)

Клиентский мод: рисует рамки-хитбоксы игроков поблизости, в том числе сквозь блоки.

- Клавиша **H** включает и выключает (меняется в Настройки → Управление).
- Ближние игроки (до 12 блоков) красные, дальние жёлтые. Дальность 64 блока.
- Свои игроки не рисуются, только чужие.
- Настройки (дальность, цвета, толщина) в начале файла
  `src/main/java/com/example/playerhitbox/HitboxRenderer.java`.

Нужны: Minecraft 1.21.11, Fabric Loader 0.19.3+, Fabric API 0.141.6+, Java 21.

## Как собрать

### Вариант 1: GitHub Actions (ничего не нужно ставить)
1. Создай пустой репозиторий на github.com и загрузи в него всё содержимое этой папки
   (вместе с папкой `.github`).
2. Открой вкладку **Actions** и дождись зелёной галочки (несколько минут).
3. Открой завершённый запуск и скачай **Artifacts → player-hitbox**: внутри `.jar`.
4. Файл без `-sources` в названии положи в папку `mods`.

### Вариант 2: у себя на компьютере
Нужны Java 21 и Gradle 9.5.1:

    gradle build

Готовый файл появится в `build/libs/` (нужен тот, что без `-sources`).
